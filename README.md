### 🚀 Featured Projects

**[TripMate — Multi-Agent AI Travel Planner](https://github.com/sarveshamrute10) · [Live]**
Multi-agent system built with LangGraph, where a Supervisor agent orchestrates specialized agents through a FastAPI backend. Integrates a custom MCP server for tool-calling access to external domain data, with input guardrails and a Human-in-the-Loop approval flow for draft travel plans.

**NSE India Market Intelligence Platform — Azure Databricks Lakehouse**
End-to-end Medallion architecture pipeline ingesting 15M+ historical NSE trading records via Auto Loader, with automated schema evolution and quality-gate enforcement between Bronze/Silver layers, Z-Order/liquid clustering for query optimization, and orchestration via Airflow.

**Internal Text-to-SQL Chatbot — JPMorgan Chase**
Built using LangChain and JPMC's internal LLM Suite, with Pinecone for schema metadata retrieval and a Streamlit front end for interactive natural-language querying.
